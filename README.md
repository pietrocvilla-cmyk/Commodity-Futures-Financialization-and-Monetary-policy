# Has Futures Markets Financialization Changed Monetary Policy Transmission to Commodity Prices?

MSc in Economics — London School of Economics and Political Science
EC424 — MSc Thesis, May 2026

## Abstract

This research examines whether the financialization of commodity futures markets that happened
in the first 10 years of the 2000s has changed the transmission of monetary policy to commodity
prices in the US. Using an instrumented local projections strategy with high-frequency monetary
policy surprises, I estimate the evolution of the causal effect of monetary policy on commodity
futures prices allowing this effect to vary with two measures of financialization: the non-commercial
gross share of open interest and the rolling correlation with S&P 500 returns. I find that
financialization amplified monetary policy transmission for industrial commodities — copper and
oil — through a risk appetite channel, while results for agricultural commodities are more muted.
A subsample comparison confirms that monetary policy transmission changed significantly in the
post-financialization period relative to the pre-financialization period for the former.

## Repository Structure

The repository is organized as follows:

- `Futures_financialization_and_monetary_policy.Rproj` - Open this first; sets the working directory for all R scripts
- `code/` - Contains all R and Stata analysis scripts
  - `00 Download data.R` - Downloads FRED-accessible raw data
  - `01 Financialization measures creation.R` - Builds the two financialization measures
  - `02 Analysis.do` - Cleans, merges, and constructs the LP-IV dependent variables
  - `03 Parsimonious bootstrapping.R` - Pre/post subsample bootstrap comparison (reported in the thesis)
- `data/` - Contains all raw and intermediate data files
  - `Commodity prices/` - LSEG — manual download required
  - `Controls/` - Industrial production, inflation, exchange rates (FRED, downloaded automatically)
  - `DTA/` - Generated by the Stata code; not raw input data
  - `Financialization of commodities/` - CFTC/LSEG-derived — manual download required
  - `Monetary policy surprises/` - Fedfunds & Treasury (FRED, automatic); Mps_data (manual)
- `output/` - Empty initially; will contain figures and tables after running the scripts
  - `00 Descriptives/` - Descriptive statistics and plots
  - `01 Baseline/` - Baseline LP-IV impulse response results
  - `02 Interaction model/` - Interaction-effect (financialization) results
  - `03 Bootstrap/` - Pre/post subsample bootstrap results
  - `04 Robustness Checks/` - Robustness check results

## Setting Up Directories

This project mixes R and Stata code, and each language handles project-relative paths differently.

### R scripts

1. Open `Futures_financialization_and_monetary_policy.Rproj` (double-click it) — this
   automatically sets your working directory to the repository root, so every relative
   path in the R scripts (e.g. `"Data/Controls/Indpro.xlsx"`) will resolve correctly.
2. Do **not** edit any paths in the R scripts — they are already relative to the repo root
   and will work as-is once the `.Rproj` file is open.

### Stata scripts

Stata has no equivalent auto-detection mechanism. At the top of `Data cleaning.do` and
`Analysis.do`, edit the one line:

```stata
global root "C:/Users/yourname/path-to-this-repo"
```

to point to wherever you cloned this repository. Use forward slashes (`/`), even on
Windows — this keeps the path portable across operating systems. Every other path in the
Stata code is built from this single global, so nothing else needs to be edited.

## Data Sources

Run `download_data.R` first (after opening the `.Rproj` file) — it automatically downloads
every series available from FRED, and creates placeholder `_README.txt` files documenting
exactly what to download manually for restricted-access data:

| Data | Source | Access |
|---|---|---|
| S&P 500, Fed funds rate, Treasury yield (DGS1), Industrial production, CPI inflation, USD/AUD, USD/BRL, USD/CLP exchange rates | FRED | Automatic (`download_data.R`) |
| Commodity futures prices | Refinitiv (LSEG) Datastream | Manual — institutional license required |
| Non-commercial gross share of open interest | CFTC Commitments of Traders | Manual — download link in placeholder file |
| Monetary policy surprise (Mps_data) | Acosta et al. (2025), U.S. Monetary Policy Event-Study Database (USMPD), Federal Reserve Bank of San Francisco | Manual — [link](https://www.frbsf.org/research-and-insights/data-and-indicators/us-monetary-policy-event-study-database/) |
| Oil supply news shock | Känzig (2021) | Manual — [github.com/dkaenzig/oilsupplynews](https://github.com/dkaenzig/oilsupplynews) |
| Geopolitical Risk (GPR) Index | Caldara & Iacoviello (2022) | Manual — [matteoiacoviello.com/gpr.htm](https://www.matteoiacoviello.com/gpr.htm) |

**Sample period**: January 1990 – January 2026 for all raw series, except the CFTC
non-commercial gross share measure, which is exported over 1992–2025 in
`Financialization data analysis.R` due to CFTC data availability constraints (intentional,
not an error).

## How to Run the Pipeline

1. `download_data.R` — downloads FRED data, creates placeholders for manual downloads
2. Manually retrieve the LSEG, CFTC, USMPD, Känzig, and GPR data per the table above
3. `Financialization data analysis.R` — builds the two financialization measures and
   descriptive plots
4. `Data cleaning.do` — imports and cleans all raw series into individual `.dta` files
5. `Analysis.do` — merges everything into `master_panel_gs1.dta` and constructs LP-IV
   dependent variables
6. `Parsimonious bootstrapping.R` — runs the pre/post financialization subsample
   comparison reported in the thesis
7. `IRF.R` — estimates and plots the baseline and interaction-effect impulse responses
